# se inscreve, o defeito nascia no pior momento possível: com uma banda real
# esperando a arte, sem aviso nenhum antes.

#

# hoje, trocando o motor do recorte sem ninguém pedir — exatamente o contrário do que
# este arquivo existe para evitar.
#
# Então a ordem foi: a conferência diária rodou uma vez, imprimiu o que a oficina
# instala de verdade, e só então os números entraram aqui.
